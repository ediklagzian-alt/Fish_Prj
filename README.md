# Fish_Prj

В папке `data/` собраны данные, необходимые для анализа и обучения эвристической модели:

- `cities.csv` — справочник российских городов с координатами (широта и долгота).
- `moon_phases_UTC_1800-2050.csv` — справочник лунных фаз. Изменение состояния фазы луны в зависимости от географического положения почти не изменяется, так что это можно посчитать за допустимую погрешность и взять календарь на много лет вперед.
- `raw/weather/` — сырые JSON, полученные с OpenWeather.

## Источники данных

- **Города:** https://raw.githubusercontent.com/hflabs/city/master/city.csv
- **Фазы луны:** https://raw.githubusercontent.com/isaacbernat/moon-data/refs/heads/main/moon_phases_UTC_1800-2050.csv
- **Погода:** [OpenWeatherMap API](https://openweathermap.org/api)
- **Спрос:** [Яндекс Wordstat](https://wordstat.yandex.ru/)

## Анализ данных

Исследовательская часть проекта реализована в Jupyter Notebook (analys/..). В ходе анализа были получены следующие результаты:

### 1. Анализ сезонности (Актуальность)
На основе выгрузки из Яндекс Wordstat было проанализировано количество запросов, связанных с клёвом рыбы. 
* **Вывод:** Спрос имеет ярко выраженную сезонность. Пик запросов приходится на май–август, а зимой наблюдается спад и минимальное количество запросов. Это подтверждает актуальность разработки веб-сервиса, особенно в весенне-летний период.

### 2. Анализ факторов, влияющих на клёв
На основе изучения предметной области (экспертные статьи, форумы рыбаков, разговоры с ИИ) была составлена модель распределения весов факторов. 

Все факторы разделены на 3 группы:
1. **Природные драйверы (65%):** Погода и давление (30%), Сезон и температура воды (20%), Нерест (15%). *Эти данные сервис может спрогнозировать автоматически.*
2. **Время и астрономия (20%):** Время суток (15%), Фаза Луны (5%).
3. **Зона ответственности рыбака (15%):** Место ловли (10%), Снасти (5%). *Сервис не может это предсказать, но может выдать рекомендации.*

* **Вывод:** Основное влияние вносят прогнозируемые природные факторы. Влияние фазы Луны было мной переоценено, и теперь  учитывается как модификатор, а человеческий фактор выносится за рамки автоматического прогноза.
